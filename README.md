# of translator for linux
Entirely copied from byzp original project [of-tools](https://github.com/byzp/of-tools) however the translator only functions on Windows.

Reworked by me i reworked the translation side to use my system and to test Hailo AI capability at translating messages then Cursor used to rework and finish the rest of the project as it was left and forgotten about for months until i decided finish this up.

Has to be ran as a sudo user for the permissions to sniff the web traffic.

My config uses [Gemma Translate](https://ollama.com/library/translategemma) with ollama on an external server but with a sufficiently powerful gpu you could run this locally.
